# О проекте

В этом проекте совершаю попытку описать установку и настройку системы документирования Docsify.

Поделюсь собственным мнением. За период работы в IT получен опыт работы с различными системами для документирования.
Перечислю: Atlassian Confluence, DokuWiki, MediaWiki, Wordpress и другие. У каждой из этих систем есть свои плюсы 
и минусы. Не возьмусь сказать, что какая-то из них хорошая, а какая-то плохая. Каждая из них хороша для своего спектра
задач, либо, что не маловажно: имеет поддержку вендора и согласованность компонентов.

Docsify - это opensource решение. Она работает с популярным форматом разметки Markdown, хранение слоя данных 
реализуется в файлах. В Docsify встроена возможность настроить боковое меню, навигацию, главную страницу, темы 
и подключить плагины для расширения возможностей. Из минусов выделю, что все, что не идет "из коробки" может 
конфликтовать с коробочным решение либо влиять на другие плагины / темы / поведение - это плата за opensource.

Возможностей Docsify "из коробки" для моих задач более чем достаточно. Мне нравится эта система. Надеюсь вам она тоже
понравится. Возможно с данной ВиКи порог вхождения для использования Docsify снизится и количество пользователей
использующих Docsify увеличится.

Желаю Вам приятного чтива и более комфортного погружения в Docsify.
