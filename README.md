# Документация по установке и настройке Docsify

## Установка Docsify

### Установка пакетного менеджера NPM

1. Загрузите установочный файл Node.js для своей ОС с официального сайта Node.js ( https://nodejs.org/ ).
2. Запустите установочный пакет и следуйте инструкциям на экране, чтобы завершить процесс установки.
3. Откройте окно терминала и введите следующую команду, чтобы убедиться, что Node.js и npm установлены правильно:
```bash
node -v
npm -v
```

### Установка Docsify

#### Глобальная установка

Если вы хотите установить docsify глобально, чтобы ОС "знала" о месте установки, наберите в терминале команду:

```bash
npm install docsify-cli -g
```

#### Локальная установка

В данном примере умышленно ставлю docsify локально (в команде не указываю ключ -g). Лично мне так удобнее.

```bash
npm install docsify-cli
```

Для удобства работы с локально установленным docsify создаем файл "docsify" следующего содержания:

```bash
#!/bin/bash
./node_modules/.bin/docsify $1 $2 $3 $4
```
Для его запуска добавляем права исполнение:

```bash
chmod +x docsify
```
## Проверка работы

Проверяем успешность установки:

```bash
docsify --version # для варианта глобальной установки
./docsify --version # для варианта локальной установки
## Пример

➜  docsify --version

➜  docsify-cli version:
➜    5.0.0
```

## Запуск проекта

Для запуска проекта на web-сервере в Терминале вводим команду:

```bash
./docsify serve название_проекта
```
Например:

```bash
docsify serve docsify-wiki
## Пример вывода в Терминал после запуска
Serving /Users/admin/IdeaProjects/docsifyPrivate/docsify-wiki now.
Listening at http://localhost:3000
```
